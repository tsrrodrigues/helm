The Pill

A tiny signal that says everything

The pill floats in the corner of your screen — always visible, zero distraction. Colored dots show running agents. The number shows how many are waiting for you.

Focus Mode

Context before you jump

When an agent transitions to waiting, opening the panel shows a focus card — not the full list. You see the project, the task name, how long it's been waiting, and an AI-generated summary of what the agent needs.

Press Enter to jump straight to the terminal. Press x to dismiss and see the next waiting agent. Press Tab to see all sessions.

You never land in a terminal blind. You always know what's waiting.

Full Panel

All your fronts, one view

Sessions are grouped by project with color-coded borders. Each front shows a live summary: how many agents are running, how many are waiting.

Click any row to jump to that pane in your terminal. Waiting agents glow amber. Running agents show green. ⌘1–9 jumps directly by position.

Inline rename, drag to reorder, create new sessions and windows — all without leaving the overlay.

Notifications

You'll never miss a prompt

When an agent goes from running to waiting, three things happen:

1. The pill bounces — a subtle physical nudge in the corner of your eye.
2. A native macOS notification fires — even if the terminal is hidden.
3. The waiting dot starts blinking — amber, pulsing, unmissable.

No browser tabs to check. No terminal windows to cycle through. The agent finishes, you know.

Under the Hood

Smart state detection

Helm polls tmux every 2 seconds, capturing the last lines of each pane. No agent plugins needed — it reads the terminal output directly.

🟢 Running

Detects spinners (✻ ◆ ⠋), activity text ("Thinking...", "Writing..."), or output that changed since last poll.

🟡 Waiting

Output stable for 3s+ with a recognized prompt (>, y/n, "How should I proceed?"). Fallback: 8s stable without prompt.

⚫ Idle

Pane command is a shell (bash/zsh/fish) with no agent running. Editor panes (vim/nvim) are tracked separately.

🧠 AI Task Names

Each pane gets a human-readable task name generated from the agent's context via the Anthropic API. Updates as the agent progresses.

📝 Wait Summaries

When an agent starts waiting, Helm generates a summary of what it needs — so you have context before jumping in.

🖥️ Terminal Nav

Click "ir →" and Helm selects the tmux pane + activates the WezTerm tab. Cross-referenced via TTY mapping.

And More

Built for the parallel agent workflow

🎨 Project Colors

Each project gets a deterministic accent color — blue, purple, green, orange, pink, or cyan. Sessions from the same repo are visually grouped.

🔄 Live Reload

Edit daemon.js, main.js, or renderer files — changes apply instantly. No restart during development.

📐 Zero Chrome

Transparent Electron window. No title bar, no borders. Only the pill and panel are visible. Mouse passthrough on all transparent areas.

🔋 Low Overhead

Window collapses to pill size when closed — 95% less GPU compositing. Discrete 1.5s blink instead of 60fps CSS animations.

⚙️ LaunchAgent

npm run service installs a macOS LaunchAgent. Starts on login, stays alive, auto-restarts. Logs in ~/.helm/logs/.

🔌 Debug API

curl http://127.0.0.1:7374/debug shows raw pane output, detection results, and timing — for tuning detection on new agents.
